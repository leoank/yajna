# The notebook

This directory is the vault: every page here is part of the record. Open it in any
markdown editor. `yajna new`, `yajna log` and the other commands fill the templates and
keep the IDs straight; `yajna validate` checks every page.

Layout: `projects/PRJ-*/` holds experiments, runs, analyses and artifacts per project;
`protocols/`, `materials/`, `equipment/`, `builds/` and `agents/` are shared; `log/<year>/`
has one file per day per author; `references/` holds reading notes by citation key;
`tasks.md` holds todos not tied to a page.
