# The notebook

This directory is the vault: every page here is part of the record. Open it in any
markdown editor. `docs/conventions.md` says how to write an entry; `yajna new`, `yajna log`
and the other commands fill the templates in `templates/` and keep the IDs straight.

Layout: `projects/PRJ-*/` holds experiments, runs, analyses and artifacts per project;
`protocols/`, `materials/`, `equipment/`, `builds/` and `agents/` are shared; `log/<year>/`
has one file per day per author; `tasks.md` holds todos not tied to a page.
